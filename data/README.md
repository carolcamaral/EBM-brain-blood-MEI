# Input data (not included)

Individual-level genomic data and patient information are not distributed with this repository.
To run the analyses, place the following files in this folder:

- `ALUall.final_comp_original.vcf`, `LINE1.all.final_comp_original.vcf`, `SVAall.final_comp_original.vcf`: MELT v2.1.5 group VCFs (all samples genotyped jointly).
- `RIPs (Brain_Blood) - Patient Info.xlsx`: sample sheet (sheet `RIPsPerronProjectwoPD`) and subject information (sheet `SUBJECT INFO`: subject, age at death, sex, brain region, diagnosis).

Access to these data can be requested from the corresponding author.
